# 变更记录

## 0.1.4 — 本地兼容候选，未发布

- compatibility 改为 schema 2：frameworkApi 1、框架版本 `[0.2.0, 0.3.0)`、精确 Tower `4.9.0`、`smtx: "none"`。
- SMTX 产品版本不作为插件的全局准入条件；这不声明任意主机具备 SMART 采集兼容性，也不替代 SSH 目标身份、命令人工审核、返回序列号和样本提交保护。
- 前端 `web/plugin.js` 与原始 0.1.3 包逐字节一致，许可证不变。配置 schema、权限、SSH 声明、历史格式和功能行为均未改变；旧 0.1.3 包原样保留。
- 补充严格 schema 2、版本上下界、API/Tower 不匹配和旧包拒绝的离线验证；服务夹具仍使用非执行 stub，不作为实机采集证据。
- 不包含尚未接通的 device-policy v2，不恢复 SSH 审批或每日计划。新框架／插件组合尚未实机验收，真实有效 SMART 健康样本仍未取得。
