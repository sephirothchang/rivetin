## 页面结构依据

本预览参考了获授权只读观察的实际网络拓扑页与 VDS 详情，恢复横向四列对象关系：

1. 虚拟机：按虚拟机网络分组。
2. 虚拟分布式交换机：VDS 与虚拟网络初始按组排列，使用独立对象和关联线，编辑时可以自由布局；管理、存储用途单独标识。
3. 主机：网桥 / bond 分组、active-backup 模式、A/B 成员网口、可展开的未使用网口。
4. 物理交换机：LLDP 邻居和端口，物理网卡连接到对应端口。

保留点阵画布、资源树、集群页签、对象折叠、选中连线、详情抽屉、显示连线、缩放与专注视图。数据全部合成，使用文档保留地址和独立模拟标识。没有复制真实设备名称、地址、资源 ID、MAC 或原始页面图像。预览仅复现对象组织和局部交互，不宣称完整复刻官方界面或接入真实网络接口。

## 左侧组件库与自动创建

进入“编辑拓扑”后，左侧组件库中的图例可以拖入画布，也可以点击创建：

- **分布式交换机（VDS）**：拖到画布空白处，立即生成 `VDS-Custom-01` 等唯一名称的交换机草稿；业务用途、默认 MTU 1500、active-backup，不自动占用网卡。
- **虚拟网络**：拖到可编辑 VDS 卡片上，自动在该 VDS 内创建网络草稿；拖到画布空白处时，原子地配套创建一个新 VDS 和一个虚拟网络。
- 新对象标记“新建”；从组件库拖到空白处时放在落点，点击创建时按组排列。右侧详情可调整本轮新建对象的名称、VDS MTU 或网络 VLAN；修改后点击“更新对象草稿”。已有对象的身份、用途和参数不因此开放修改。
- 名称自动去重。网络默认优先选择该 VDS 尚未使用且模拟上联已覆盖的 VLAN；没有合适的新 VLAN 时复用现有 VLAN，并在审查中明确提示二层共享风险。仍需人工核对用途与标签。
- 管理、存储和只读本地桥不能作为创建网络的目标。主机、物理网卡、LLDP 物理交换机只作为已有资源图例，不通过拖拽创建硬件。
- 创建项与网口绑定一起进入变更清单。仅创建对象也需要保存审查和 90 秒人工二次确认；超时、手动回滚或正常停止会完整恢复快照，移除未确认的新对象。
- 尚无主机上联的新 VDS 会明确提示不能承载跨主机流量；可再把该 VDS 右侧圆形连接点拖到指定主机，配置可编辑网口。新增网络的 VLAN 会对已有相关主机逐一检查。
- 本 Demo 上限为 20 个 VDS、80 个虚拟网络；超限创建整体拒绝，不留下半个父子对象。画布随对象数量扩展。

这些动作自动创建的是本页内存草稿，保存后的生效也仅为模拟。正式自动创建仍需主框架提供受控 API 与可恢复事务。

## 编辑语义与操作路径

默认浏览模式不支持拖拽编辑。点击“编辑拓扑”后：

- **自由移动**：拖动可编辑 VDS 的标题栏，或虚拟网络卡片；VDS 移动时带着当前子网络一起移动，虚拟网络也能独立移动。连线随位置实时更新。只移动位置不会新增拓扑变更，不需要保存网络事务。键盘聚焦移动区域后可用方向键微调，Shift 加速；Esc 或取消手势恢复拖动前位置。重置视图恢复初始布局。布局只保存在本页内存，不写共享配置。
- **虚拟网络关联**：把网络左侧圆形连接点拖到可编辑 VDS，更新所属关系；卡片位置保持不变。原网络 ID、名称、用途、VLAN 和虚拟机引用保持不变，保存审查列出原 / 目标 VDS、潜在中断及目标上联 VLAN 风险。拖动卡片本身仅改变位置。
- **垃圾桶删除**：只有拖动已放置的、本轮新建且尚未确认的 VDS / 虚拟网络时，左下出现红色区域；拖入后撤销该新建草稿。删除新 VDS 同时撤销它的新建子网络，并将指向它的网口草稿恢复到本轮基线归属。如果该新 VDS 接入了已有虚拟网络，删除会被拒绝，须先把已有网络连回其他 VDS。已有对象与已二次确认的新对象不支持删除；管理、存储和只读本地桥及其子网络始终锁定。

- 展开主机未使用网口，将 `Demo-Node-01 / eth8` 拖入同一主机的迁移 bond，即增加一条模拟上联。也可拖到目标 VDS，按网卡所属主机更新绑定。
- 网口拖到其他主机的 bond 会被拒绝。网口拖入本主机的未使用区域可解除绑定，保存前会检查是否断开网络。
- 将可编辑 VDS **右侧圆形连接点**拖到一个具体主机，打开该主机的上联配置；选择网卡并点击“更新上联草稿”。这一步只改变草稿，不开始计时。
- VDS 右侧连接点拖到另一个可编辑 bond 时，预选那个 bond 的网口，但仍需人工确认选择，再保存到草稿和进行风险审查。
- **不存在 VDS 互拖后交换全体主机上联的操作或模型 API。** 单次 VDS 上联配置只影响所选主机的目标 VDS；原归属网络的风险同样参与检查。
- 点击 VDS 后可查看详情，展示网桥、active-backup 模式、每台主机的活动 / 备用网口。A/B 仅为本 Demo 的模拟角色，不是对真实内核活动成员的检测。

画布宽 2400 个逻辑像素，高度随对象扩展，移动坐标受画布边界限制。支持横向、纵向滚动，缩放为 50%–150%；小视口可用“适应画布”或专注视图查看四列，卡片内容不压缩成另一种拓扑结构。

## 保护与风险预判

模拟清单有 3 台主机、5 个 VDS、30 个物理网口。每主机 `eth0/eth1` 承载管理，`eth2/eth3` 承载存储；管理 VDS 中还包含普通 `default` 虚拟机网络。即使存在普通网络，**整个管理 VDS 和关联网口仍受保护**。本地虚拟网桥没有可验证物理上联，保持只读。

保护不仅发生在 UI：模型与应用前校验拒绝受保护 VDS 增减网口、移动相关 NIC、修改角色 / 身份 / 事实；未知角色、角色与内嵌网络用途矛盾、清单不完整时拒绝修改。复合上联更新还核对 NIC 主机归属和唯一性，原子地产生一个主机的草稿。

| 校验 | 结果 |
| --- | --- |
| 管理、存储、共享上述 VDS 的普通网络及关联 NIC | 硬保护 |
| 只读本地桥、未知角色或不完整清单 | 拒绝编辑 |
| 跨主机物理网口绑定 | 拒绝编辑 |
| 变更后无可用上联 | 阻断应用 |
| MTU 不足或缺少目标 VLAN | 阻断应用 |
| 单网口、单故障域、可用单链路速率上限下降 | 提示对象级风险 |
| 虚拟网络更换所属 VDS | 提示潜在中断并检查目标 VLAN / MTU |
| 任何上联变更 | 提示丢包 / 业务中断风险 |

active-backup 只有一条转发链路，因此不将活动和备用网口的带宽相加。预判比较模拟可用成员的最大单链路速率上限，不代表实际吞吐或当前活动链路能力。

阻断演示：将 `eth9`（MTU 1500）绑定到业务 VDS（MTU 9000），或在上联配置中取消某主机业务 VDS 的所有网口。可以保留草稿继续修正，不能绕过风险门禁应用。

## 保存、90 秒确认与离开

流程：草稿 → 差异与风险审查 → 勾选风险认知 → 应用模拟变更 → 90 秒内人工二次确认。

点击“应用模拟变更”时重新预检，保存变更前内存快照，再应用模拟状态并开始固定 90 秒窗口。支持人工确认保留或立即回滚；未确认则恢复快照。到期时刻及之后拒绝迟到确认。下一次事务以最近一次已确认状态为回滚基线。

pending 期间禁止编辑、丢弃和重复应用。计时采用绝对截止时间，轮询只刷新显示；浏览器脚本暂停时可能延迟执行回调，但恢复运行及确认前重新检查期限，过期则恢复快照。正常 stop/dispose 恢复 pending 并清理 DOM、监听器、观察器和定时器。

退出编辑有“取消、丢弃并退出、审查保存并退出”选择。页面关闭 / 刷新前存在草稿或 pending 会触发浏览器原生离开提示。重新打开页面会重建初始模拟数据。

**这些均为页面内存模拟，不是服务器端网络事务。** 不承诺浏览器崩溃、断连、进程重启后的真实网络回滚。功能配置不存入 localStorage；语言跟随文档 lang，不另存全局语言偏好。

## 正式接入缺口

只读观察页面不等于真实版本适配验收。本 Demo 没有可信的实时拓扑 / 权限 / 并发版本，也没有物理交换机配置探测、真实 LACP / bond / 路由 / ACL / 虚拟机依赖或连通性检测。

正式实现需要主框架统一设计可信用途与对象身份、完整清单、新鲜度、管理员授权、并发控制、服务器端快照 / 回滚、幂等操作、任务状态查询和审计。90 秒期限必须由独立于浏览器的可信服务执行，覆盖部分失败、客户端断连和服务重启。网络事务不能冒充普通共享配置 PUT。

## Rivetin 接入契约

当前目录、包名和 ID 均为 `rivetin-network-topology`，描述文件 `rivetin.json`；工厂注册在 `window.RivetinPlugins`，使用 `RivetinSDK`。标准包为 `rivetin-package-v1` / `rivetin-global-v1`，制品扩展名 `.rivetin.json`。配置只使用 `/api/rivetin/v1/config` 和当前 ID，不做历史 ID、目录、API 或格式回退，不迁移或双写旧配置。

既有 `0.1.0` 固定描述文件中 `towerBuilds` 为空，原字节保留。`0.1.3` 源码声明 frameworkApi 1、最低框架 0.2.6、Tower 4.9.0、SMTX none 与 inventory.read；4.9.0 为框架核验的产品版本及本次有限实测版本，不代表本插件已完成所有功能、用途保护或版本适配测试。工作页只接收窄上下文和专属 provider，实际接口及服务端授权由框架提供。包格式校验成功不代表已经完成安装或启用。配置规范见 [Rivetin 配置契约](../../docs/rivetin-configuration.md)。原作者的许可证与署名按原文保留。
