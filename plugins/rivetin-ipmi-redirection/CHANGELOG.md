# 版本记录

## 0.1.4（候选）

- 修复停用期间完成资产请求后，重新启用不能重试读取的问题；隔离旧激活的请求结果，重新启用时重读清单。
- 清单没有当前主机或读取失败时，不把其集群归属视为已确认，保持普通跳转。
- 模拟登录发起后若插件停用、主机切换或已保存登录设置改变，不再继续导航。
- 本地演示只安装 IPMI 候选，移除与跳转无关的 SSH 内置包依赖，避免旧包被框架 0.2 兼容性门禁拒绝导致演示启动失败。
- 权限、配置 schema/默认值与兼容性范围保持不变；保留固定 0.1.3 及历史 0.1.2 制品。

本候选已在 CloudTower 4.9.0 开发测试环境完成框架 0.2.0 下的限定真实组合验收，覆盖字段增强、配置草稿/保存退出、统一入口及停用/重启；仅使用一个授权管理员会话并独立回读 API。双有值地址切换、剪贴板读写、跨管理员、真实服务故障注入及后续框架组合仍未验收，详见 [验证范围](README.md#014-组合验收)。真实 BMC 网页自动登录未接入，未新增设备/固件支持；失败处置保持确认候选后禁用并保留备份待修，不承诺自动恢复旧包。

## 0.1.3

- 更新兼容性声明为 schema 2：CloudTower 4.9.0、框架 API 1、Rivetin >=0.2.0 且 <0.3.0。
- 声明 `smtx: "none"`，表示此插件无需 SMTX OS 版本准入；不表示所有主机、BMC 厂商或固件均已适配。
- 保持 0.1.2 的插件自有功能源码、权限、配置 schema、默认配置和生命周期语义不变。
- 常规构建重新打入当前框架的共享 HTTP 客户端及多语言资源，可执行包字节因此变化；共享客户端的固定错误码、404 和不重试写入等行为已增加离线回归校验。
- 正式功能仍为 HTTPS 地址跳转；MegaRAC SP-X 自动登录仅有本地模拟，生产网页自动登录尚未接入。
- 保留原 0.1.2 发布包，本版本使用独立的 0.1.3 制品，不覆盖历史包。

本次变更不新增真实 CloudTower 或 BMC 的验证结论。
