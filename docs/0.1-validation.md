# 0.1 验证范围

核验日期：2026-10-27。框架及首个子插件均为 0.1.0；验证平台为 CloudTower 4.9.0 RC，服务复用平台已有 Node.js 20.12.1 镜像。源码构建与测试使用 Node.js 22。下述真实环境结果属于此前部署验收，不代表便携式安装器已通过真实部署验收。

## 自动化

`npm test`：框架 26 项、IPMI 插件 53 项，共 79 项通过。覆盖包路径/摘要/权限/元数据校验，生命周期与回滚、备份、单插件损坏、独立文件和最后保存语义、跨进程 CLI 禁用、HTTP 认证与 Origin、Tower 身份适配、语言跟随、草稿退出与功能清理，以及现有 BMC 模拟契约。

Windows 对已删除文件偶发延迟回收引起测试清理 ENOTEMPTY；生成目录已加边界检查与有限重试，未忽略断言或跳过测试。最终全套通过。

构建包含框架正式/演示 Island、IPMI 旧兼容 Island、子插件与演示宿主。框架 Island、框架服务与子插件 JSON 包均按脚本生成；服务包和前端包携带 MIT 许可证。不上传 node_modules、运行配置、日志或凭据。

## 真实环境验收

- 新增独立 PluginKit Deployment/Service/Ingress；官方 Tower Pod 保持运行，容器重启计数未增加。没有操作其他 VM，也未使用快照恢复。
- 通过 Tower 现有注册机制挂载框架，子插件安装并显式启用。主机概览 IPMI 字段增强为 HTTPS 链接，保留复制入口。
- 读取真实可见集群并生成默认集群例外，经 Web 保存后读取服务端配置确认。
- 匿名读取配置/状态/日志返回 401；错误 Origin 写入返回 403；未知配置字段返回 400，原配置保持不变。
- 实际 API 紧急禁用、Web 恢复，以及本机 CLI 禁用和恢复均经过页面回读；IPMI 增强撤销/恢复，Tower 主机页面和插件中心仍可使用。
- 正式 Island 订阅 Tower 共享 i18n，全局中文界面显示中文插件入口。中英文切换与编辑中的草稿保留另有自动化与本地浏览器验证。
- PluginKit 操作日志可通过 Web 查看。原生审计 SDK 写入接口存在，但该测试版本明确限制系统用户，root 亦被拒绝；未借用内部系统身份或改数据库。限制及镜像失败状态如实显示。

## 已知边界

故障隔离按用户决定为 TODO。框架自身 Web 自更新、自动配置 schema 迁移、后端可执行子插件、发布者签名、日志自动轮转尚未实现；框架更新目前使用 CLI 安装器。更新 schema 版本会拒绝，避免未经验证迁移。

IPMI 插件当前真实环境只启用登录页跳转。MegaRAC 网页自动登录和其他厂商 Redfish 仍为本地模拟/协议契约验证，未把模拟测试称为真实 BMC 验收。没有创建新的 Tower 用户来模拟多角色；实际原生身份验收使用获准管理账户，非管理员分支由自动化覆盖。

此记录说明实际验证范围，不代表厂商认证或不存在未知缺陷。
