## 扫描范围与结果

初始只读扫描覆盖当时的 95 个受控文件、13 个可达提交及 151 个唯一 UTF-8 Git 文本版本，无因解码失败而跳过的文本版本。扫描规则未检出个人绝对路径、私网 IPv4 地址、私钥正文或符合所用令牌规则的凭据。该结果受规则和覆盖范围限制，不证明不存在任何秘密。

当前内容的 24 处回环地址和 57 处本地开发措辞，多数用于演示入口、测试夹具和开发说明。环境关键词匹配中包含 4 处真实 GitHub 仓库所有者名称，它们属于有意公开的仓库链接，不作为个人路径泄漏。原始命中内容及调查输出保留在忽略目录，不随仓库发布。

GitHub 上不可达或已删除的对象、缓存、分叉仓库、Wiki、Issue、Actions 制品和 Release 附件未纳入此次 Git 文本历史扫描，不能据此声称已清除所有平台副本。

## 整改清单

| 项目 | 处置 | 原因与边界 |
|---|---|---|
| 会话专属部署授权 | 从根目录和插件 `AGENTS.md` 删除，改为当前任务的明确授权规则 | 仓库文档不能延续或扩大某次会话的操作授权 |
| 个人测试环境叙述 | 将验证入口改为产品构建、运行时及验证条件 | 保留必要兼容性证据，移除个人环境归属描述 |
| 文档中的回环链接 | 改为明确的开发示例地址和代码文本 | 避免 GitHub 读者误认为在线演示入口 |
| 合法公共链接 | 保留仓库、官方 API 与许可证入口 | 不把有意公开的作者/仓库标识错误删除 |
| 模拟环境说明 | 保留回环监听、保留地址及模拟限制 | 避免将本地演示误当成真实 BMC 能力或生产部署方式 |
| 发布前检查 | 增加 `npm run check:public` | 仅输出命中位置和类别，不回显疑似敏感值；模式检查仍需人工复核 |
| 便携式制品 | 使用显式嵌入清单、忽略运行目录和 `-trimpath` | 构建后仍应检查实际制品、许可证、摘要和内容边界 |
